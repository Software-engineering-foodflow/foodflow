## 功能
| 範圍 | 必驗條件 |
| --- | --- |
| 報廢 | EXPIRED/SPOILED/DAMAGED/OTHER依既有列舉；OTHER補充必填；正數三位小數、不可超量；紀錄/帳本同交易；ROUND_HALF_UP、未知NULL；員工不含金額；停用品可報廢；URL預選批次；成功失效快取 |
| 全數報廢 | 對話框抓剩餘量快照、預設過期、可改原因、每次新操作開啟新key；結果未知的舊操作關框重開保留原key與快照；只提交明確數量；衝突顯示最新量並重新核對；匯出hook及元件供預警組員接入 |
| 盤點 | ADMIN預覽與確認；多筆、原因、實際量非負、批次不得重複；expected_quantity加最新數量異動編號；舊確認及同量改回拒絕；預覽快照一致、確認鎖內比對；無差額不寫異動；來源REVERSED拒絕；任一失敗全回滾；重送不再次調整 |
| 異動 | 五項篩選、分頁、時間/操作者/來源單據/批次/增減/前後量/原因/非FEFO；沖銷原紀錄；位置獨立；唯讀；批次歷程頁的完整整合為隊友依賴 |
| 統計 | 確認時間台北起日含、迄日次日不含；公式平衡；沖銷歸原類型且反映當期；期初非零無當期異動仍列；不同食材不併量；報廢按分組鍵與unit分開、明細可展開、已知成本合計與未知筆數；管理者伺服器檢查 |
