食序 FoodFlow 系統架構圖
使用者層
«單一門市・電腦／平板瀏覽器»
管理者店長：資料、權限、報表
一般員工收貨、廚房備料：進貨、領用、報廢
前端層
«React 單頁應用（SPA）・TypeScript・Vite・Mantine»
頁面與元件features/*/pages
表單、表格、預警首頁
資料 Hooksfeatures/*/hooks.ts
TanStack Query 快取與失效
API 函式features/*/api.ts
型別由 OpenAPI 產生
HTTP 用戶端shared/api/client.ts
唯一的 fetch・錯誤格式・401 導回登入
共用介面　shared/ui（PageHeader、DataTable、StatusBadge…）＋ app/theme.ts 設計系統
後端應用層
«FastAPI 單一應用・依八大功能分 10 個模組・API → Service → Repository»
身分驗證與權限auth/dependencies.py
JWT（HttpOnly Cookie）・角色 RBAC
API 層（Controller）router.py・schemas.py
Pydantic 驗證輸入・組成回應
統一錯誤處理app/main.py exception handler
DomainError／驗證錯誤 → HTTP 錯誤格式
共用支援Clock：SystemClock／FixedClock
UnitOfWork：一筆交易 commit／rollback
dependencies.py：建構子注入組裝
Service 層（業務邏輯）service.py
商業規則・交易範圍・列鎖順序
Idempotency-Key／單據狀態機防重送
領域規則與策略FefoStrategy／ManualStrategy
AlertRuleFactory → 4 條 AlertRule
classify_expiry・is_low_stock
站內預警 AdapterAlertNotifier → InAppNotifier
以 API 回應投遞，不對外連線
StockLedger（庫存唯一寫入入口）inventory/ledger.py
批次列鎖・餘量・位置・異動紀錄
Repositoryrepository.py 介面
＋ SQLAlchemy 實作
資料庫層
«Docker Compose・持久化 Volume»
PostgreSQL 17（主資料庫）12 張表・PK／FK／唯一與檢查限制
批次、單據、庫存異動、報廢紀錄
Alembicmigration 管理 schema 版本
備份與還原backup.sh・restore.sh（pg_dump）
部署：開發時 Vite 將 /api 代理到後端；展示時由 FastAPI 一併提供前端靜態檔，兩者都同源。預警在查詢時即時計算，首版沒有背景工作與訊息佇列。
